## 3. Next 3 steps (E7 items)

1. **Finish E7's item basics.** `gen_items.py` is done; still to do:
   - Give the test bag some new items (e.g. in `SovereignTest_SetupNewGame`, `src/script_manager.c`) and check them
     on screen.
   - Real icons, from PokeAPI item sprites converted to 24×24 / 16 colours, credited in CITATIONS.
   - Mint and Ability Capsule/Patch use functions.
   - The reference notes below are kept for this work.
   - How items work in the decomp:
     - IDs come from `decomp/generated/items.txt`: append before `MAX_ITEMS`, after `ITEM_SECRET_KEY` (#467).
     - Each `ITEM_X` reads `decomp/res/items/data/x.json`. Fields: name, plural, article, description (≤3 lines,
       ≤40 chars each), icon `{sprite, palette}`, price, holdEffect, fieldPocket, fieldUseFunc and so on. Copy the
       shape of `choice_band.json`.
     - `tools/dataproc/src/itemproc.c` packs the data and generates the name/description text banks.
     - Icons are `res/items/icons/<x>.png` + `.pal`, listed in `res/items/icons/meson.build` and
       `res/items/item_icon.order`.
     - Hold effects are listed in `decomp/generated/item_hold_effects.txt`.
     - Evolution items use `ITEM_USE_FUNC_EVO_STONE`; itemproc sets `partyUseParam.evolve` for those.
   - Take prices, descriptions and fling data from PokeAPI's `item_*.csv` files (pinned commit:
     `tools/POKEAPI_COMMIT`).
   - Placeholder icons can come from PokeAPI's item sprites, the way the species icons did. Credit them in
     CITATIONS.
   - New hold effects start as `HOLD_EFFECT_NONE`; their battle effects are a later checklist step.
   - Mints and the Ability Capsule/Patch need new field-use functions (QoL item).
2. **Check item names on screen.** Platinum's longest item name is 12 characters, but many new names are 14–19
   (Heavy-Duty Boots, Ultranecrozium Z, Unremarkable Teacup, and Mega Stones like Charizardite X). The bag's name
   buffer is 18 characters (`src/applications/bag/main.c:1009`). Test what fits in the bag list, the shop list and
   the battle bag, then add a short-name table like `SHORT_NAMES` in `gen_new_species.py` for anything that
   overflows. Also check bag pocket capacities against the new items.
3. **Wire up the 16 waiting evolutions** (rerun `gen_new_species.py` once the items exist), then the shops.
   - New held items go on sale at the Veilstone Department Store (owner).
   - Evolution items: Renegade's Snowpoint seller.
   - Mega Stone vendors: `docs/MegaEvolution.md`.
   - After E7: held-item forms (Crowned Zacian/Zamazenta, Ogerpon masks) under milestone FM, then E8 (Mega
     Evolution).

**Also pending:** a read-only survey of the decomp's item system (limits, bit widths, bag sizes, shop data) was
running in a subagent at handoff. If it's lost, redo it before writing `gen_items.py`.

**Testing tips:**
- Test ROM: `tools/test/build_test_rom.sh` → `decomp/build_test/pokeplatinum.us.nds`.
  - A cold build takes about 40 minutes on 4 cores. Install the apt packages from `decomp/INSTALL.md`, then
    `pip install py-desmume pillow pyyaml openpyxl`.
- The docs CI job runs `tools/regenerate_docs.sh /tmp/pokeapi/data/v2/csv decomp` and fails on any diff in `data/`
  or `docs/`.
  - Generated docs (`MegaEvolution.md`, `PostgameLegendaries.md` and so on) must be edited through their generators
    in `tools/design/`.
  - Fetch PokeAPI at the pinned commit as the workflow does.
- Booting a battery save is more reliable than `new_game.sh`, whose intro timing shifts between builds. Make an
  in-game save (menu → SAVE → YES, YES, wait about 1,800 frames, then `export:`). Boot it with `drive.py ... sav:FILE`
  and continue with `wait:600 A wait:200 START wait:200 A wait:300`.
- `drive.py`'s `PLAYER_X/Z_ADDR` read (0,0) on current builds and need re-finding.
- Easy Chat (test build): `SELECT+B`, then `A A` opens the POKéMON group.
