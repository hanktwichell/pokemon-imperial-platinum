# Overworld sprite sizes

The size class of each post-game legendary's overworld sprite (owner, 2026-10-24). The owner draws the final sprites
(E12); today's are placeholders drawn by `tools/sprites/make_legendary_overworld.py`, which holds the classes. Platinum's
own legendaries keep their vanilla sprites and sizes.

| Class | Frame | Platinum examples |
|---|---|---|
| Small | 32×32 | Uxie, Mesprit, Azelf, Heatran, Darkrai, Cresselia, Shaymin |
| Large | 64×64 | Dialga, Palkia, Giratina (Altered), Arceus, Regigigas |
| Extra large | 128×64 | Giratina (Origin) |

## Set by the owner

- **Extra large:** Eternatus.
- **Large:** Necrozma, Koraidon, Miraidon, Kyogre, Groudon, Rayquaza. Not in the game yet (their sprites come with their encounters): Ho-Oh, Lugia, Lunala, Solgaleo.
